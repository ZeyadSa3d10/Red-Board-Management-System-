# نظام إدارة الفروع — صلاحية المالك (Owner)

## مقدمة

هذا الدليل يشرح بالتفصيل كل شاشة وكل زر وكل وظيفة متاحة لحساب **المالك** في النظام. المالك هو المستخدم الذي يملك صلاحية الوصول الكامل لجميع فروع النظام وإدارة جميع الكيانات (موظفين، فروع، منتجات، عملاء، موردين، تقارير، مخزون).

---

## 1. لوحة التحكم الرئيسية — Dashboard

**المسار:** `/owner/dashboard`

### الغرض
شاشة رئيسية تعرض ملخص سريع لأداء جميع الفروع في لمحة واحدة.

### المحتوى

**بطاقات الإحصائيات (Stat Cards) — 6 بطاقات:**
1. **قيمة المخزون الكلي** — إجمالي قيمة البضاعة الموجودة في جميع الفروع (الكمية × متوسط التكلفة)
2. **ديون العملاء** — إجمالي المبالغ المستحقة على العملاء (فواتير آجلة غير مسددة)
3. **المستحق للموردين** — إجمالي المبالغ التي لم تدفع للموردين
4. **عدد الفواتير** — إجمالي فواتير البيع المسجلة في النظام
5. **إيراد الشهر** — صافي الإيرادات في الشهر الحالي
6. **ربح الشهر** — صافي الربح في الشهر الحالي

**شريط مؤشرات الأداء (KPI Bar):**
- عدد الفروع النشطة
- إجمالي الإيرادات (حسب الفترة المحددة)
- إجمالي الأرباح
- أفضل فرع أداءً

**الرسم البياني:**
- **رسم بياني مساحي (Area Chart)** — يعرض الإيرادات والأرباح الشهرية على مدار السنة
- **رسم بياني أعمدة (Bar Chart)** — يقارن أداء الفروع من حيث الإيرادات والربح

**جدول ترتيب الفروع:**
- عرض جميع الفروع مرتبة حسب الإيرادات تنازلياً
- يظهر لكل فرع: الإيرادات، المرتجعات، صافي الإيراد، تكلفة البضاعة (COGS)، الربح، هامش الربح %، عدد الفواتير، متوسط قيمة الفاتورة

**فلترة الوقت:**
- أزرار لاختيار الفترة: اليوم، هذا الشهر، هذه السنة، أو نطاق زمني مخصص (من — إلى)

### الأزرار والإجراءات
- **اختيار الفترة** — تغيير الفترة الزمنية لجميع البيانات في الصفحة
- تحديث تلقائي عند تغيير الفترة

## 2. المبيعات والأرباح — Sales

**المسار:** `/owner/sales`

### الغرض
عرض جميع فواتير البيع والمرتجعات من جميع الفروع مع إمكانية البحث والتصفية والعرض التفصيلي.

### المحتوى

**شريط مؤشرات (KPI):**
- إجمالي المبيعات (صافي بعد خصم المرتجعات)
- عدد فواتير البيع
- عدد فواتير المرتجع
- إجمالي عدد الفواتير المعروضة

**شريط التصفية (FilterBar):**
- **بحث نصي** — بحث برقم الفاتورة، اسم العميل، أو اسم الفرع
- **نطاق تاريخي** — من تاريخ / إلى تاريخ
- **نوع الفاتورة** — كل الأنواع، بيع نقدي، بيع آجل، مرتجع مبيعات، مرتجع آجل
- **الفرع** — اختيار فرع محدد
- **طريقة الدفع** — نقدي، فيزا، شيك، آجل (ذمم)
- **عدد الفلاتر النشطة** — يظهر شارة بعدد الفلاتر المطبقة حالياً
- **زر إعادة ضبط** — إلغاء جميع الفلاتر

**جدول الفواتير:**
- رقم الفاتورة
- التاريخ والوقت
- اسم الفرع
- النوع (بيع نقدي، بيع آجل، مرتجع مبيعات، مرتجع آجل) — كل نوع بلون مختلف
- اسم العميل
- الإجمالي
- طريقة الدفع — وتعرض أيضاً حالة الدفع للفواتير الآجلة (آجل، مدفوع جزئياً، تم التسديد)
- زر عرض التفاصيل (عين)

**نافذة تفاصيل الفاتورة (Modal):**
- معلومات الفاتورة: الفرع، التاريخ، العميل، طريقة الدفع
- جدول أصناف الفاتورة: اسم المنتج، الكمية، سعر الوحدة، الإجمالي
- الملاحظات
- الإجمالي النهائي

### الأزرار والإجراءات
- **زر العين** — فتح نافذة تفاصيل الفاتورة
- **فلترة** — جميع أدوات الفلترة تبحث في جميع فواتير النظام عبر الفروع
- **إعادة ضبط** — مسح جميع الفلاتر

## 3. التقارير الشاملة — Reports

**المسار:** `/owner/reports`

### الغرض
منصة تحليلات متقدمة مكونة من 6 تبويبات تغطي جميع جوانب الأداء المالي والتشغيلي.

### 3.1 تبويب الأرباح والخسائر (PnL)

#### المحتوى
**شريط فلترة:**
- الفترة: اليوم، هذا الشهر، هذه السنة، مخصص
- عند اختيار "مخصص": يظهر حقلين لتحديد تاريخ البداية والنهاية
- الفرع: كل الفروع أو فرع محدد

**8 بطاقات إحصائيات:**
1. إجمالي الإيرادات
2. المرتجعات
3. صافي الإيرادات (الإيرادات - المرتجعات)
4. تكلفة البضاعة المباعة (COGS)
5. إجمالي الربح (صافي الإيرادات - COGS)
6. هامش الربح % (الربح / صافي الإيرادات × 100)
7. عدد الفواتير
8. متوسط قيمة الفاتورة

**الرسوم البيانية:**
- **الاتجاه الشهري (RevenueChart)** — رسم بياني مساحي يعرض الإيرادات الشهرية
- **الإيرادات vs التكلفة والهامش (PnlMiniChart)** — رسم بياني يجمع الإيرادات والتكاليف والهامش

### 3.2 تبويب التقرير اليومي (Daily)

#### المحتوى
**شريط فلترة:**
- اختيار التاريخ

**شريط مؤشرات (KPI):**
- إجمالي المبيعات
- إجمالي المرتجعات
- صافي الإيرادات

**الرسوم البيانية:**
- **توزيع طرق الدفع (PaymentPieChart)** — رسم بياني دائري يوضح توزيع النقدي / فيزا / شيك / آجل
- **أداء الفروع** — رسم بياني أعمدة يقارن أداء الفروع في النقدي والفيزا والشيك

**جدول تفاصيل الفروع:**
- اسم الفرع
- نقدي
- فيزا
- شيك
- آجل بيع
- آجل محصل
- مرتجعات
- صافي اليوم
- عدد الفواتير
- مع صف إجمالي في الأسفل

**زر تصدير CSV** — تصدير بيانات التقرير اليومي إلى ملف CSV

### 3.3 تبويب مقارنة الفروع (Branch Comparison)

#### المحتوى
**شريط فلترة:**
- الفترة: اليوم، هذا الشهر، هذه السنة، مخصص
- عند اختيار "مخصص": تاريخ البداية والنهاية

**شريط مؤشرات (KPI):**
- أعلى فرع إيراداً (اسم الفرع + القيمة)
- أعلى فرع ربحاً (اسم الفرع + القيمة)
- إجمالي الإيرادات
- إجمالي الأرباح

**الرسم البياني (BranchComparison):**
- مقارنة مرئية لأداء الفروع

**جدول تفاصيل المقارنة:**
- رقم الترتيب (وسام ذهبي/فضي/برونزي للمراكز الثلاثة الأولى)
- اسم الفرع
- الإيرادات
- المرتجعات
- صافي الإيراد
- COGS (تكلفة البضاعة)
- الربح
- هامش الربح %
- عدد الفواتير

**زر تصدير CSV**

### 3.4 تبويب المنتجات (Products)

#### المحتوى
**شريط فلترة:**
- الفترة
- تاريخ مخصص (من — إلى)
- الفرع
- ترتيب حسب: الإيراد / الكمية / الربح
- عدد النتائج: Top 10 / Top 20 / Top 50 / الكل

**قسم "أعلى المنتجات مبيعاً":**
- رسم بياني أعمدة أفقي (TopProductsChart) — يعرض أعلى المنتجات حسب المعيار المختار
- رسم بياني أعمدة أفقي لتوزيع الكميات

**جدول المنتجات:**
- الترتيب
- الباركود
- اسم المنتج
- الكمية المباعة
- الإيرادات
- التكلفة
- الربح
- هامش الربح %

**قسم "قيمة المخزون":**
- جدول بقيمة المخزون في كل فرع
- الإجمالي الكلي

### 3.5 تبويب الآجل والعملاء (Deferred)

#### المحتوى
**شريط فلترة:**
- الفترة (للتحصيلات): هذا الشهر، هذه السنة، مخصص
- تاريخ مخصص (من — إلى)

**شريط مؤشرات (KPI):**
- إجمالي الديون
- عدد العملاء بديون
- أعلى عميل ديناً

**الرسوم البيانية:**
- **توزيع أعمار الديون (AgingStackChart)** — رسم بياني مكدس يوضح تصنيف الديون حسب الفترة (0-30 يوم، 31-60 يوم، 61-90 يوم، +90 يوم)
- **رسم بياني أعمدة للتصنيف العمري** — يوضح توزيع المبالغ حسب الفئة العمرية

**جدول تحليل الأعمار:**
- اسم العميل
- 0-30 يوم
- 31-60 يوم
- 61-90 يوم
- +90 يوم
- الإجمالي

**قسم "التحصيلات":**
- رسم بياني (CollectionsChart) — يوضح اتجاه التحصيلات خلال الفترة
- جدول تفاصيل التحصيلات: التاريخ، العميل، المبلغ

### 3.6 تبويب الرواتب (Salary)

#### المحتوى
**شريط فلترة:**
- الشهر (1-12)
- السنة (2024, 2025, 2026, 2027)
- الفرع

**شريط مؤشرات (KPI):**
- إجمالي الرواتب
- إجمالي السلف
- عدد الموظفين

**الرسم البياني (SalaryChart):**
- توزيع الرواتب

**بطاقة ملخص:**
- متوسط الراتب
- أعلى راتب

**جدول تفاصيل الرواتب:**
- اسم الموظف
- الراتب
- السلفة
- الصافي
- تاريخ الصرف

**زر تصدير CSV**

### الأزرار والإجراءات العامة في التقارير
- **طباعة** — طباعة الصفحة الحالية
- **تصدير CSV** — في التبويبات التي تدعمه (اليومي، مقارنة الفروع، الرواتب)
- **فلترة** — كل تبويب له أدوات الفلترة الخاصة به

## 4. المخزون الكامل — Inventory

**المسار:** `/owner/inventory`

### الغرض
إدارة المخزون في جميع الفروع — عرض المنتجات، كمياتها في كل فرع، إضافة منتجات جديدة، تعديل المنتجات.

### المحتوى

**LowStockAlert (تنبيه المخزون المنخفض):**
- يعرض تحذيراً إذا كان هناك منتجات低于 الحد الأدنى للمخزون
- يظهر عدد المنتجات التي تحتاج لإعادة تموين

**شريط الفلترة (FilterBar):**
- بحث بالاسم أو الباركود
- تصفية حسب الفئة (كل الفئات)

**StockTable (جدول المخزون):**
- الكود / الباركود
- اسم المنتج
- الفئة
- الوحدة (قطعة، كيلو، متر، لتر، كرتونة، شيكارة، طقم)
- لكل فرع عمود منفصل يعرض الكمية في ذلك الفرع
- عمود الإجمالي (مجموع الكميات في كل الفروع)
- متوسط التكلفة
- سعر البيع الحالي
- القيمة الإجمالية (الكمية × متوسط التكلفة)
- الحالة (منخفض / متوفر) — شارة ملونة
- زر تعديل (قلم رصاص)
- زر حذف (سلة مهملات)

### الأزرار والإجراءات

**إضافة منتج:**
- الضغط على زر "إضافة منتج"
- نافذة منبثقة تحتوي على:
  - اسم المنتج (مطلوب)
  - الباركود
  - التصنيف (مطلوب) — قائمة منسدلة بالتصنيفات الموجودة
  - الوحدة (مطلوب) — قطعة، كيلو، متر، لتر، كرتونة، شيكارة، طقم
  - سعر البيع الحالي (مطلوب)
  - أقل سعر بيع (مطلوب)
  - الحد الأدنى للمخزون (افتراضي: 10)
  - سعر الشراء
  - **كميات وتكاليف الفروع** — لكل فرع يمكن إدخال:
    - الكمية الابتدائية
    - تكلفة الوحدة

**تعديل منتج:**
- الضغط على زر القلم الرصاص بجانب المنتج
- نفس نافذة الإضافة لكن بالبيانات الحالية

**حذف منتج:**
- الضغط على زر سلة المهملات
- تأكيد الحذف (نافذة تأكيد)
- ملاحظة: لا يمكن حذف منتج مرتبط بمعاملات سابقة

**بحث وتصفية:**
- البحث الفوري في الجدول بالاسم أو الباركود
- تصفية حسب الفئة

## 6. الموظفون والرواتب — Employees

**المسار:** `/owner/employees`

### الغرض
إدارة جميع الموظفين في النظام — إنشاء، تعديل كلمة المرور، تفعيل/تعطيل، حذف، وصرف الرواتب.

### المحتوى

**DataTable (جدول الموظفين):**
- اسم الموظف
- الدور (مدير، محاسب، موظف) — شارة ملونة
- الفرع التابع له
- الراتب
- الهاتف
- الحالة (نشط / غير نشط) — شارة ملونة
- أزرار الإجراءات

وظيفة **بحث** مدمجة في الجدول

### الأزرار والإجراءات

**إضافة موظف:**
- الضغط على زر "إضافة موظف"
- نافذة منبثقة تحتوي على:
  - الاسم (مطلوب)
  - رقم الهاتف (مطلوب)
  - كلمة المرور الافتراضية (مطلوب)
  - الدور: موظف، محاسب، مدير
  - الفرع
  - الراتب
  - الرقم القومي
  - تاريخ التعيين
  - زر "إضافة"

**صرف راتب:**
- يتم بالضغط على صف الموظف في الجدول (إذا كان له راتب)
- نافذة منبثقة تعرض الشهر الحالي ومبلغ الراتب
- زر "تأكيد الصرف"
- ملاحظة: زر الصرف يظهر فقط إذا لم يتم صرف راتب الشهر الحالي مسبقاً

**تغيير كلمة المرور:**
- زر "كلمة السر" في إجراءات الموظف
- نافذة منبثقة لإدخال كلمة المرور الجديدة
- زر "حفظ"

**تفعيل / تعطيل:**
- زر "تفعيل" أو "تعطيل" حسب الوضع الحالي
- تغيير فوري لحالة الموظف دون الحاجة لتأكيد

**حذف موظف:**
- زر "حذف"
- نافذة تأكيد
- لا يمكن التراجع عن الحذف

## 8. العملاء — Customers

**المسار:** `/owner/customers`

### الغرض
إدارة العملاء — عرض، إضافة، تحصيل الديون، وكشف حساب.

### المحتوى

**بطاقات الإحصائيات — 4 بطاقات:**
1. إجمالي الديون (المبالغ المستحقة على العملاء)
2. إجمالي العملاء
3. عملاء تجاوزوا الحد الائتماني (At Risk) — أو تجاوزوا 80% من الحد
4. عدد فواتير الآجل المفتوحة

**تنبيهات العملاء المعرضين للخطر:**
- عرض العملاء الذين استهلكوا أكثر من 80% من الحد الائتماني
- يظهر اسم العميل ونسبة الاستخدام

**شريط الفلترة:**
- بحث باسم العميل

**جدول العملاء:**
- اسم العميل
- رقم الهاتف
- النوع (شركة / فرد)
- إجمالي الديون
- الحد الائتماني
- نسبة الاستخدام (شريط تقدم ملون: أخضر ≤50%، أصفر 50-80%، أحمر >80%)
- زر عرض (كشف حساب)
- زر تحصيل (دفعة)

**عند اختيار عميل معين:**
- يظهر جدول بفواتير الآجل الخاصة به:
  - رقم الفاتورة
  - النوع (بيع آجل / مرتجع آجل)
  - الفرع
  - المبلغ الأصلي
  - المدفوع
  - المتبقي
  - تاريخ الاستحقاق
  - الحالة (مدفوعة كلياً / مدفوعة جزئياً / غير مدفوعة)

**كشف الحساب:**
- نافذة منبثقة تعرض حركة الحساب:
  - التاريخ
  - البيان (مبيعات آجلة، مدفوعات، مرتجعات)
  - مدين
  - دائن
  - الرصيد

### الأزرار والإجراءات

**إضافة عميل:**

## 9. الموردين — Suppliers

**المسار:** `/owner/suppliers`

### الغرض
إدارة الموردين — عرض، إضافة، سداد المستحقات، وكشف حساب.

### المحتوى

**بطاقات الإحصائيات — 4 بطاقات:**
1. إجمالي المستحق للموردين
2. إجمالي المدفوعات
3. عدد الموردين
4. فواتير الشراء المفتوحة

**شريط الفلترة:**
- بحث باسم المورد

**جدول الموردين:**
- اسم المورد
- رقم الهاتف
- العنوان
- إجمالي المشتريات
- المدفوع
- المستحق (شارة حمراء إذا كان هناك مبلغ مستحق)
- زر عرض (كشف حساب)
- زر دفع

**عند اختيار مورد معين:**
- يظهر جدول فواتير الشراء الخاصة به:
  - رقم الفاتورة
  - التاريخ
  - الفرع المستلم
  - إجمالي الفاتورة
  - المدفوع
  - المتبقي
  - الحالة (مدفوعة / مدفوعة جزئياً / غير مدفوعة) — شارة ملونة
  - تاريخ الاستحقاق
  - اسم المشروع

**كشف الحساب:**
- نافذة منبثقة تعرض حركة الحساب:
  - التاريخ
  - البيان (فواتير شراء، مدفوعات)
  - مدين
  - دائن
  - الرصيد

### الأزرار والإجراءات

**إضافة مورد:**
- زر "إضافة مورد"
- نافذة منبثقة: الاسم، الهاتف، التصنيف، العنوان

**دفع مورد:**
- زر "دفع" بجانب المورد
- نافذة منبثقة تحتوي على خيارين:
  - **دفع مستقل** — مبلغ بدون ربطه بفاتورة معينة، مع إدخال طريقة الدفع والتاريخ
  - **ربط مع فاتورة شراء** — اختيار فاتورة شراء محددة وسدادها كلياً أو جزئياً
- زر "تأكيد"

**كشف حساب:**
- زر "كشف حساب" بجانب المورد
- يعرض حركة الحساب كاملة

## ملخص وظائف عامة

### نظام البحث
- **بحث نصي** في جميع صفحات الجداول — يبحث فورياً أثناء الكتابة
- يبحث في عدة أعمدة في نفس الوقت (مثلاً: رقم الفاتورة، اسم العميل، اسم الفرع)

### نظام التصفية (FilterBar)
- يوجد نمطين:
  - **Simple** — للصفحات البسيطة (بحث + اختيارات قليلة)
  - **Panel** — للصفحات المعقدة مع مجموعات فلترة معنونة وأيقونات
- مزامنة مع URL: عند تطبيق فلتر، يظهر في رابط الصفحة، ويمكن مشاركة الرابط مع نفس الفلاتر
- عداد الفلاتر النشطة: يظهر عدد الفلاتر المطبقة حالياً

### التنبيهات (Notifications)
- تظهر بعد كل عملية (إضافة، تعديل، حذف)
- ألوان: أخضر (نجاح)، أحمر (خطأ)، أصفر (تحذير)

### النظام البصري
- واجهة باللغة العربية بالكامل
- أيقونات توضيحية بجانب العناوين والأزرار
- ألوان مختلفة لأنواع البيانات (أخضر للمدفوع، أحمر للمستحق، إلخ)
- دعم كامل للهواتف والأجهزة اللوحية (Responsive Design)

### تصدير البيانات
- CSV: متوفر في تقارير (اليومي، مقارنة الفروع، الرواتب)
- Excel: متوفر عبر API للفواتير والتقارير
- PDF: متوفر عبر API للفواتير
