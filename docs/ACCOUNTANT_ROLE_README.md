# دور المحاسب في نظام بناء材料 ERP

## نظرة عامة

يعد دور المحاسب في نظام بناء材料 ERP مسؤولاً عن إدارة الجوانب المالية والمحاسبية للنظام. يوفر النظام أدوات شاملة تساعد المحاسب على مراقبة المخزون، إدارة الحسابات، وتحليل الأداء المالي للفروع.

## الصلاحيات والوصول

يمكن للمحاسب الوصول إلى:

1. لوحة تحكم المحاسب
2. إدارة المخزون الكامل
3. التقارير المالية الشاملة
4. إدارة حسابات الموردين
5. عرض الفواتير والمعاملات

## الوصف التفصيلي للصفحات المتاحة للمحاسب

### 1. لوحة تحكم المحاسب (AccountantDashboard)

#### الهدف

عرض ملخص عام للحالة المالية والمخزنية للنظام في نظرة سريعة.

#### المكونات الرئيسية:

- **بطاقات الإحصائيات (StatCards):**
  - قيمة المخزون الكلي: تظهر إجمالي قيمة المخزون الحالي بجميع الفروع
  - ديون العملاء:แสดง المبلغ المستحق من العملاءؤخرين
  - المستحق للموردين:显示 المبلغ المستحق للموردين
  - عدد الفواتير:显示 إجمالي عدد الفواتير الصادرة

- **جدول حسابات الموردين:**
  - يعرض قائمة الموردين مع تفاصيل:
    - اسم المورد
    - إجمالي المشتريات
    - المبلغ المدفوع
    - المبلغ المستحق (مع تلوين أحمر للفت الانتباه)
  - يدعم البحث عن الموردين بالاسم
  - يستخدم تنسيق العملة لعرض القيم المالية

### 2. المخزون الكامل (AccountantInventory)

#### الهدف

عرض جميع منتجات المخزون مع تفاصيل الكميات والقيم across جميع الفروع.

#### كيف يعمل:

- يستدعي API للحصول على جميع بيانات المخزون (`api.getAllStock()`)
- يعرض البيانات باستخدام مكون StockTable المتقدم
- يد خاصية التحميل أثناء جلب البيانات من الخادم

#### ما يراه المحاسب:

- جدول شامل يحتوي على:
  - كود المنتج (الباركود أو المعرف)
  - اسم المنتج
  - الفئة
  - الوحدة
  - المخزون في كل فرع (مع فرز فروع خاصة)
  - المخزون الإجمالي
  - متوسط التكلفة (إذا كان الصلاحية تسمح)
  - سعر البيع
  - القيمة الإجمالية بالتكلفة أو حسب سعر البيع
  - حالة المخزون (منخفض/متوفر) مع تنبيه بصري
  - أزرار التعديل والحذف (إذا كان الصلاحية تسمح)

### 3. التقارير المالية (AccountantReports)

#### الهدف

提供深入的财务分析和报告，用于决策制定和绩效监控.

#### يحتوي على أربع علامات تبويب رئيسية:

**العلامة التبوية 1: الأرباح والخسائر (P&L)**

- تحليل الإيرادات والتكاليف وصافي الربح
- اختيار الفترة (اليوم، هذا الشهر، هذه السنة، مخصص)
- تصفية حسب الفرع
- عرض:
  - إجمالي الإيرادات
  - إجمالي التكاليف
  - صافي الربح (الإيرادات - التكاليف)
  - عدد الفواتير

**العلامة التبوية 2: التقرير اليومي**

- تركيز على أداء يوم محدد
- تفاصيل المبيعات، المرتجعات، مدفوعات الآجل
- تفاصيل السداد النقدي (نقداً، فودافون كاش، شيكات)
- عدد الفواتير اليومية

**العلامة التبوية 3: الآجل والعملاء**

- متابعة الحسابات المدينة (ما يدين به العملاء)
- تحليل تقدم التحصيل على مدار الوقت
- عرض إحصائيات الآجل:
  - إجمالي الآجل
  - المجموع المدفوع
  - المتبقي
- جدول التحصيلات مع تفاصيل التاريخ، العميل، المبلغ

**العلامة التبوية 4: المنتجات**

- تحليل أداء المنتجات
- ترتيب المنتجات حسب الكمية المباعة أو الإيراد
- عرض قيمة المخزون الإجمالية
- جدول المنتجات الأكثر مبيعًا مع:
  - الترتيب
  - اسم المنتج
  - الكمية المباعة
  - الإيراد Generated

## التقنيات المستخدمة في الواجهة الأمامية

- **React مع hooks:** useState, useEffect, useMemo لإدارة الحالة والتأثيرات الجانبية
- **React Icons:** для отображения интуитивных иконок (BsTruck, BsCashCoin, etc.)
- **مكونات مخصصة مُعادة الاستخدام:**
  - StatCard: لعرض الإحصائيات بطاقات جذابة
  - FilterBar و FilterGroup و FilterSearch: لتوفير واجهة موحدة للبحث والتصفية
  - Spinner: لعرض حالة التحميل
  - EmptyState: لعرض رسالة عند عدم وجود بيانات
- **أدوات مساعدة (utils):**
  - formatCurrency: لتنسيق العملة الموحد
  - formatDate: لتنسيق التواريخ
- \*\*اتصال بالخادم
